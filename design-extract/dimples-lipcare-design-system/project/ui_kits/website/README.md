# Dimples Lipcare — Marketing Website

A pixel-perfect recreation of the Dimples Lipcare marketing site, designed to match the brand brief: glossy, soft, classy, feminine. Lives at desktop 1440 design width.

## Sections (top to bottom)
1. **Header** — monogram, nav (Shop / Trainings / Journal / Contact), bag, search
2. **Hero** — serif italic headline, lead, primary CTA, hero product staging
3. **Trust strip** — "All in one lipcare brand" + brand pillars
4. **Products section** — five product cards in a grid
5. **Ritual** — three-step "How to use" with sparkle hairlines
6. **Trainings section** — five training offers in a deep-pink panel
7. **Testimonial** — single quote on petal background, with stars
8. **Newsletter & contact** — inputs + the four contact pills
9. **Footer** — small print, social, secondary links
